# T10
# 海洋環境感測器管理系統 (Marine Environmental Sensor Management System)
本研究採取數位分身（Digital Twin）原型建構法，建置一個名為 ocean_db 的海洋環境感測器管理系統。該系統以 CRUD (新增、讀取、更新、刪除) 邏輯為核心，實現虛擬模型與實體感測數據的同步映射。

## 一、 環境與基礎建設 (Infrastructure Setup)
資料庫連線配置：首先透過 db.php 建立系統與 MySQL 資料庫之間的核心連線設定（採用 PDO 模式），確保水溫、pH 值及鹽度等即時數據能正確存取。

資料結構規格化：依據第三正規化 (3NF) 原則，於資料庫內建立 users 與 sensors 資料表，並透過外鍵建立管理者與感測設備間的權責關聯。

## 二、 身份驗證與導航介面 (Authentication & Navigation)
入口與權限管理：開發 login.php 作為系統入口，實作 Session 驗證機制確保治理數據安全，並由 logout.php 處理安全登出邏輯。

共用元件開發：製作 navbar.php 導覽列，整合數位分身監控面板、設備部署、歷史紀錄等功能選項，以便管理人員在不同治理功能間快速切換。

## 三、 核心功能開發 (Core Functionalities)
本階段依據數位分身管理流程實作四大功能：

數位分身建立 (Create)：透過 create.php 供管理人員輸入新部署感測器的位置與初始參數，於資料庫中生成對應的虛擬映射實體。

數據映射與呈現 (Read)：開發 index.php 作為數位分身監控中心，即時讀取感測器回傳之環境指標，並透過狀態標籤（正常/異常）直觀呈現海域健康度。

參數調校與維護 (Update)：利用 edit.php 進行數位分身參數的校正或手動調整（如模擬氣候變遷情境），並同步更新設備的運作狀態（如維護中）。

實體退役 (Delete)：實作 delete.php 以執行移除毀損或已退役的感測器紀錄，維持數位治理平台的數據精確性。
